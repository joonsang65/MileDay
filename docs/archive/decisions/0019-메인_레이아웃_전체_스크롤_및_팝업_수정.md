# 메인 레이아웃 전체 스크롤 및 팝업 표시 수정

## 배경 (Context)
* **세로 스크롤 이슈**: 브라우저 창의 세로 높이가 작아지거나 하루 보기 내의 목표/마일스톤 개수가 많아졌을 때, 하루 보기 패널이 숨겨지거나(`.detail-panel`의 `display: none` 적용) 패널 자체가 압축되면서 내부 컨텐츠가 잘리는 현상이 발생했습니다.
* **팝업 가려짐 이슈**: 달력과 하루 보기의 레이아웃을 다듬는 과정에서 하루 보기 패널 우측 상단의 `+` 버튼(Quick Menu)을 클릭했을 때 뜨는 팝업 메뉴가 다른 패널에 가려져 보이지 않는(클리핑) 문제가 발생했습니다.

## 의사결정 (Decision)
대규모 리팩터링이나 별도의 Scroll, Portal 컴포넌트를 도입하지 않고, 기존 CSS의 불필요한 제약 속성만을 걷어내는 방식으로 문제를 해결하기로 결정했습니다.

### 1. 하루 보기 숨김 처리 및 압축 방지
* **조건부 숨김 제거**: 작은 화면(`max-height: 520px`)에서 하루 보기 패널을 아예 없애버리던 미디어 쿼리를 삭제했습니다.
* **Flex Shrink 방어**: `.workspace`, `.planner-workspace`, `.day-view-panel`에 일관되게 적용되어 있던 `flex-shrink: 1` (`flex: 1 1 auto`) 및 `min-height: 0` 속성을 모두 제거했습니다. 이로 인해 뷰포트 높이가 줄어들더라도 달력과 하루 보기 패널이 압축(Squish)되지 않고 자신만의 콘텐츠 높이를 온전히 유지하게 됩니다.

### 2. 페이지 전체 스크롤 구조 확립
* **내부 스크롤 금지**: 하루 보기를 감싸는 `.side-pane`에서 `max-height: 100%`와 `overflow-y: auto`를 제거하여 패널 안에서 별도의 스크롤바가 생기지 않도록 차단했습니다.
* **Document Flow 활용**: 자식 컨텐츠들이 고유의 높이를 고집하면서 늘어나게 되면, 결국 가장 바깥에 있는 최상단 래퍼(`.app-shell`)의 `overflow-y: auto`와 `height: 100vh` 설정에 의해 화면 전체에 자연스럽게 세로 스크롤바가 생성됩니다. 
* 결과적으로 **[최상단 패널(Sticky) → 달력(현재 크기 고정) → 하루 보기(콘텐츠에 비례해 커짐) → 하단 Footer Text]** 순으로 일반적인 문서 흐름이 유지되며, 사용자는 전체 스크롤을 통해 가려진 콘텐츠에 접근할 수 있게 되었습니다.

### 3. 팝업(Quick Menu) 클리핑 해결
* 이전 작업에서 하루 보기 카드의 가로 튀어나옴을 방지하고자 래퍼 패널(`.day-view-panel`, `.side-pane`)에 `overflow-x: hidden`을 적용했었습니다.
* 하지만 CSS 명세상 한 축(`x`)에 `hidden`을 적용하면 반대 축(`y`)을 `visible`로 설정하더라도 브라우저가 이를 무시하고 `auto`(클리핑)로 처리해버리는 문제가 있었습니다. 
* 이로 인해 패널 상단을 넘어 달력 쪽으로 뻗어나가야 할 `position: absolute` 형태의 팝업이 부모 영역에 갇혀(클리핑되어) 보이지 않게 되었습니다.
* **해결**: `.day-view-panel`과 `.side-pane`에서 `overflow-x: hidden;`을 삭제하여 팝업이 자유롭게 뻗어나가도록 허용했습니다. (가로 넘침 현상은 자식 리스트(`.nested-task-list`)의 너비를 직접 제어하는 방식으로 우회하여 해결했습니다.)

## 결과 및 영향 (Consequences)
* 최소한의 CSS(flex, min-height, overflow) 삭제 및 변경만으로 복잡한 스크롤 문제와 z-index/stacking context 이슈를 모두 해결했습니다.
* 기존 DOM 구조나 React 렌더링 로직, 달력의 크기 변경 방식 등은 전혀 수정되지 않고 기존의 안정성을 유지합니다.
* 사용자는 윈도우 크기에 구애받지 않고 마우스 휠이나 터치 스크롤 한 번으로 전체 달력과 목표 현황을 연속적으로 확인할 수 있게 되어 UX가 크게 개선되었습니다.
